# AI features and privacy

TrellisFlow has separate LLM and retrieval-augmented generation (RAG) capabilities for different tasks. They are not interchangeable. Financial facts and deterministic projections are computed by application services; language models explain supplied context or answer from retrieved product documentation.

## Help Assistant

The Help Assistant answers questions about how to use TrellisFlow. It creates a retrieval embedding for the question, retrieves relevant chunks from the approved product documentation index, and provides source references for supported answers. If no retrieved source supports an answer, it withholds the unsupported answer. It does not need or retrieve your financial records.

## Money Copilot

Money Copilot is a separate, read-only financial explainer. When enabled, it can use financial context assembled by the backend for the authenticated user. It must not create or modify transactions, accounts, transfers or other financial records.

## M-Pesa parsing and transaction drafting

AI-assisted parsing or drafting can help interpret user-provided text. Review extracted information carefully. A suggestion is not a saved transaction; review and correct its amount, date, description, account, category and type, then use the normal explicit confirmation workflow. Idempotency protection prevents a repeated confirmation retry from duplicating the same write.

## Privacy and safety

- AI provider credentials are stored on the backend and must never be placed in browser code.
- The Help Assistant uses product documentation, not private financial records.
- Do not paste passwords, API keys, authentication tokens or other secrets into an assistant.
- Treat AI responses as assistance and verify important financial information against the application's records.
- The Help Assistant cannot execute financial actions.

## Forecasting is not generated by the LLM

The cash-flow forecast uses deterministic application rules over eligible account balances, posted and reconciled history, pending movements, recurring rules and known future-dated transactions. The LLM does not calculate forecast balances. Scenario outputs and uncertainty ranges are estimates with stated assumptions, not guarantees.
