# AI features and privacy

TrellisFlow has separate AI capabilities for different tasks. They are not interchangeable.

## Help Assistant

The Help Assistant answers questions about how to use TrellisFlow. It retrieves relevant sections from the approved product documentation and provides source references. It does not need or retrieve your financial records.

## Money Copilot

Money Copilot is a separate, read-only financial explainer. When enabled, it can use financial context assembled by the backend for the authenticated user. It must not create or modify transactions, accounts, transfers or other financial records.

## M-Pesa parsing and transaction drafting

AI-assisted parsing or drafting can help interpret user-provided text. Review extracted information carefully. A suggestion is not a saved transaction; use the normal review and confirmation workflow.

## Privacy and safety

- AI provider credentials are stored on the backend and must never be placed in browser code.
- The Help Assistant uses product documentation, not private financial records.
- Do not paste passwords, API keys, authentication tokens or other secrets into an assistant.
- Treat AI responses as assistance and verify important financial information against the application's records.
- The Help Assistant cannot execute financial actions.
