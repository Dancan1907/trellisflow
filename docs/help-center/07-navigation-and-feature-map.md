# TrellisFlow navigation and feature map

Use these destinations to find the main areas of the application.

| Area | Route | Purpose |
|---|---|---|
| Dashboard | `/dashboard` | High-level financial overview. |
| Personal | `/personal` | Personal containers, accounts and transactions. |
| Investments | `/investments` | Investment holdings and activity. |
| Businesses | `/businesses` | Business containers and financial records. |
| Budgets | `/budgets` | Category spending plans. |
| Goals | `/goals` | Savings targets and contributions. |
| Debt | `/debts` | Debt payoff plans. |
| Reports | `/reports` | Financial reporting and forecast entry point. |
| Cash-flow Forecast | `/reports/cash-flow-forecast` | Projected cash balances and assumptions. |
| Insights | `/insights` | Generated financial observations. |
| Money Copilot | `/money-copilot` | Read-only financial Q&A when enabled. |
| Settings | `/settings` | Account and application preferences. |
| Help Centre | `/help` | Product guidance and Help Assistant. |

The Help Assistant may recommend a destination only from this approved route map. It does not navigate automatically or perform clicks on your behalf. Use the link in its answer to open the suggested page.
