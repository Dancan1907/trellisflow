# Getting started with TrellisFlow

TrellisFlow is a financial workspace for tracking personal money, investments and businesses in one place. It brings together accounts, transactions, planning tools, reports and insights, with optional LLM-assisted financial explanations and a retrieval-augmented Help Assistant grounded in approved product documentation.

## Your dashboard

Open **Dashboard** from the application sidebar at `/dashboard`. It provides an overview of your recorded financial position and activity. The figures shown depend on the information you have entered and the reporting periods selected by each feature.

## Main areas of the application

- **Personal** (`/personal`): manage personal financial containers, accounts, categories and transactions.
- **Investments** (`/investments`): manage investment holdings and investment activity.
- **Businesses** (`/businesses`): manage business containers and their financial records.
- **Budgets** (`/budgets`): plan and monitor spending against category budgets.
- **Goals** (`/goals`): create savings goals and track contributions.
- **Debt** (`/debts`): manage debt payoff plans.
- **Reports** (`/reports`): review financial reports, including cash-flow forecasting.
- **Insights** (`/insights`): review system-generated financial observations.
- **Money Copilot** (`/money-copilot`): ask natural-language questions about your recorded finances and supported what-if scenarios when enabled. Chat analysis is read-only.
- **Help Centre** (`/help`): read the full user guide and ask the RAG Help Assistant product questions with source references when enabled.
- **Settings** (`/settings`): manage application preferences and account settings.

## Finding a feature

Use the left sidebar to move between sections. The Quick Tour introduces the main workflows. The Full User Guide explains them in detail. The Help Assistant can also explain where a feature lives and provide a direct link when its destination is known.

## Important data principles

TrellisFlow reports reflect the records you enter and the scope selected in each feature. Keep account balances, transaction dates, currencies and categories accurate. Different currencies are not automatically interchangeable unless a feature explicitly says it performs a conversion.
