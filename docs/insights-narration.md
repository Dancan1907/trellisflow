# Insights Narration (Phase 4)

## Design

Insight rules remain the source of truth. The existing engine computes and persists the insight type, severity, title, message, metadata, related entity, and action URL. Narration is optional asynchronous prose stored separately in `narrative`; it never overwrites deterministic fields.

## Processing

- The authenticated Insights UI can queue narration with `POST /api/insights/:id/narrate`.
- A scheduled worker checks the queue every 60 seconds and processes at most five insights per tick.
- The worker claims records with a conditional update to avoid duplicate concurrent work.
- Active legacy insights in `NOT_REQUESTED` are eligible for background narration; no regeneration of insight rules is required.
- Failed or stale work is recoverable. Provider/quota failures leave the deterministic insight visible.
- Narration is stored with `narrationStatus` and `narratedAt`; the dashboard refreshes to show completed narration.

## Integrity and privacy

- The model receives only the insight type, severity, deterministic title, and deterministic message. It does not receive transaction notes, arbitrary account data, or the complete financial profile.
- Insight fields are treated as untrusted data, not instructions.
- Output is bounded and rejected if it introduces numeric facts not present in the deterministic title/message.
- The UI always retains the original deterministic title and message alongside any AI explanation.
- Related app navigation uses the deterministic `actionUrl` generated by the rules engine.
- Usage events store provider/model/token counts and success only, never prompts or generated text.

## Configuration

```env
AI_INSIGHTS_NARRATION_ENABLED=false
AI_INSIGHTS_NARRATION_DAILY_LIMIT=20
NEXT_PUBLIC_INSIGHTS_NARRATION_ENABLED=false
```

Keep disabled until the database migration has been applied and provider behavior has been verified in a non-production environment. The limit is per user per UTC day and independent of Money Copilot, M-Pesa import, and natural-language drafts.

## Database

Apply the migration under `apps/api/prisma/migrations/20261126180000_insight_narration`. It adds narration state, narrative text, and narrated timestamp to existing insights. It does not change existing insight calculations or values.

## Tests

Unit coverage includes feature flag behavior, user-scoped queueing, successful narration, numeric-fact validation, and provider failure fallback. AI usage tests verify the independent quota and privacy-safe event accounting.
